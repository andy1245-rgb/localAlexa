# Phase 1 — family B: modern embedding families (BGE, E5, GTE, Jina, Nomic, Stella)

Read on 2026-11-23. One row per model; description only.

How each column was read, so any cell can be re-checked:

- **params** — Hugging Face API `safetensors.total` for the repo (a direct read of the published
  checkpoint metadata). Where the repo publishes no safetensors index the cell says so and gives the
  published checkpoint size instead. Two repos publish a parameter figure in the card that differs
  from the safetensors total; both figures are shown.
- **embedding dim** — the card's own table where it has one, otherwise config `hidden_size` plus the
  terminal module in `modules.json` (`Dense_{n}` projecting to n, where present).
- **max seq len** — the card's table where it has one, otherwise `sentence_bert_config.json`
  `max_seq_length`, otherwise config `max_position_embeddings`. Where these disagree, both are shown.
- **licence** — the card frontmatter `license:` field; for `jinaai/jina-embeddings-v4`, which has no
  `license:` field, the `LICENSE` file in the repo.
- **contrastive fine-tune support** — the module chain in `modules.json` (what pooling and projection
  the model actually ships), whether `trust_remote_code` is required, and the pooling strategy the
  card states. No claim here about whether fine-tuning is a good idea at this corpus size.
- **published speed** — searched for in each card and in the linked arXiv abstract pages. 35 of 36
  models publish no latency, throughput or per-utterance figure of any kind.
